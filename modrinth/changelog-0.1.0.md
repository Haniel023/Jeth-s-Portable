First release.

- Portable Crafting Table: a full 3x3 table with the vanilla screen and recipe book
- Portable Core Block and Portable Links: connect the chests and machines you already have, without replacing them
- Storage window: every linked chest in one searchable grid, a crafting grid that refills from storage, and a recipe book that counts what's in your chests
- Chest list: open any linked chest from afar, choose where new items go, outline a chest in the world, rename and unlink
- Machines tab: live progress for furnaces, smokers, blast furnaces and brewing stands, with remote opening and one-click collecting
- Six Core levels, from 24 blocks up to anywhere in any dimension
- From Level 3, Cores keep linked machines' chunks running while they have work
- Notifications for finished batches, no fuel, full outputs, finished brewing and full storage
- Trusted-player lists for sharing a base on a server
